## 작업 넘겨받는 법

1. `CLAUDE.md`와 `AGENTS.md`를 읽습니다.
2. `.env.example`을 `.env.local`로 복사합니다. 키가 없어도 체험 모드로 돌아갑니다.
3. `pnpm install` 뒤 `pnpm dev`로 띄우고, 처음 열면 닉네임 화면부터 모듈 4개를 한 번씩 끝까지 넘겨 봅니다. 프로필 > 설정 > "데이터 모두 지우고 처음부터"로 초기화할 수 있습니다.
4. GitHub 이슈 "작업" 양식으로 할 일을 적고(라벨 `ai-ready`), 브랜치를 만듭니다. PR을 열면 `ci.yml`이 테스트와 빌드를 돌립니다.
