## 2026-10-20 (오후)

### 디자인 바탕

- 색은 CSS 변수(`--c-*`, "r g b" 형식)로 두고 Tailwind가 그 변수를 읽게 했습니다. 다크 모드는 `[data-theme="dark"]`에서 변수만 바뀝니다. 기본은 밝게이고 프로필 > 설정에서 시스템/밝게/어둡게를 고릅니다. 시스템 설정을 자동으로 따르지 않게 한 이유는 발표 중 화면이 갑자기 어두워지는 것을 막기 위해서입니다.
- 글자 크기를 6단계(caption, small, body, heading, title, display)로 묶고 rem 으로 적어 브라우저 글자 크기 설정을 따르게 했습니다. 모션은 `--dur-fast/base/slow`와 `--ease` 토큰을 씁니다.
- 아이콘은 손으로 그린 SVG 26개를 버리고 Lucide(MIT, `lucide-react` 0.468.0) 한 세트로 바꿨습니다. 화면 코드는 짧은 이름만 쓰고 `components/Icon.tsx`에서만 실제 아이콘으로 바꿉니다.
- 화면 전환은 React Router 6.28의 `viewTransition` 옵션(View Transitions API)을 씁니다. 지원하는 브라우저에서는 추천 직무 카드의 아이콘 타일이 상세 화면 타일로 이어지고(`view-transition-name: job-tile-n`), 지원하지 않으면 기존 페이드만 남습니다.
- 데스크톱(768px 이상)에서는 상태바가 있는 폰 프레임 안에 보입니다. 실제 폰에서는 프레임 없이 꽉 찹니다. 그래서 모든 화면은 `min-h-full`이고 대화 화면만 `h-full`입니다.
- 처음 열면 `/welcome`에서 닉네임만 받습니다(실명·연락처는 받지 않음, CLAUDE.md 5절). 세션마다 한 번 짧은 스플래시가 보입니다.
- 탐색 결과 요약의 우상단 아이콘은 글자 복사 대신 1080×1920 이미지 카드(캔버스)를 만들어 Web Share로 공유하거나 PNG로 내려받습니다. 둘 다 안 되는 브라우저에서는 글자 복사로 돌아갑니다.
- 채팅: 같은 쪽 말풍선이 2분 안에 이어지면 아바타와 시각을 묶고, 새로 온 쿠키 말풍선은 글자 단위로 나타나며(최대 1.4초), 위로 올리면 "맨 아래로" 버튼이 보입니다. 면접처럼 쿠키가 아닌 상대는 `persona`(이름·표정)로 바꿉니다.
- 접근성: 보조 글자색을 #6B6B80에서 #5E5E78로 올려 연보라 배경에서 대비 4.5 이상을 맞췄고, 버튼 최소 높이 44px, `:focus-visible` 링, 토스트 `aria-live`를 넣었습니다.
- 빈 상태·오류 상태는 캐릭터 표정 이미지를 쓰는 `EmptyState` 하나로 통일했습니다. 캐릭터 파일만 바꿔 끼우면 전부 바뀝니다.

### 2~5단계 틀 (시안 없음)

- 직무 탐색 외 모듈은 시안 PNG가 아직 없어서 CLAUDE.md 5절 데이터 모델과 1절 제품 설명대로 화면을 구성했습니다. 화면 수는 CLAUDE.md의 "10화면"을 그대로 맞추지 않고 흐름이 끊기지 않는 최소 수로 두었습니다. 시안이 오면 맞춥니다.
- 경험 카드: 분류 선택 → 인터뷰(`card_ready` 이벤트) → `/api/extract-experience` 결과를 폼에 채워 고친 뒤 저장. `sourceTurns`는 사용자 메시지의 인덱스입니다. 종합 분석의 첫 버전은 LLM 없이 역량 빈도 집계로 만들었습니다.
- 자소서: 공고는 사용자가 넣은 링크 1건만 서버가 가져오고(`/api/job-post`, 8초 제한, HTML을 글자로만 변환), 실패하면 붙여넣기를 안내합니다. `example.com` 주소는 체험 공고를 돌려줍니다. 공고 분석(`/api/extract-post`)은 키워드·인재상·마감·문항을 뽑고, 마감이 있으면 "서류제출" 일정이 자동으로 생깁니다. 초안과 피드백은 하나의 API(`/api/essay-draft`, mode)로 두고 버전마다 model(쿠키/체험/내 수정)을 기록합니다.
- 홈·일정·알림: 선제 메시지는 `src/lib/nudge.ts`의 규칙 순서(마감 3일 이내 → 면접 단계인데 연습 없음 → 비어 있는 문항 → 오늘 할 일 → 직무 없음 → 카드 3개 미만 → 기본 인사)로 코드가 고릅니다. 우선순위는 `taskPriority`(남은 날 × 10 + 종류 가중치)입니다. 알림은 권한 요청과 로컬 알림까지 되고, 서버 푸시는 VAPID 키와 `web-push`를 넣어 두었지만 키가 없으면 체험 응답을 돌려줍니다. 푸시 수신은 `public/push-sw.js`를 `importScripts`로 붙였습니다.
- 면접: 유형 4개와 지원 건을 고르고 면접관 페르소나와 대화합니다. 채점 기준표(`src/data/rubric.ts`)를 지시문에 그대로 붙이고, 결과는 항목 4개 점수·근거 인용·요약을 `MockSession`에 저장합니다(`summary` 필드를 추가). 음성은 6단계입니다.
- 설정 시트에 "데이터 모두 지우고 처음부터"를 넣었습니다. 발표 시연을 반복하려면 초기화가 필요하기 때문입니다.
