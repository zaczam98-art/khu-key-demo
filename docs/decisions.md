# 결정 기록

채택한 안과 버린 안을 날짜와 함께 덧붙입니다. 지우지 않습니다.

## 2026-10-17

- 받은 데모 프로토타입을 `zaczam98-art/khu-key-demo`에 올리고 GitHub Pages로 배포했습니다. 데모는 미사용 상수 때문에 빌드가 실패해서 그 선언을 지우고, Vite base 경로와 배포 워크플로를 추가했습니다.

## 2026-10-19

- 저장소를 CLAUDE.md 구조(`src/screens`, `components/ChatShell`, Tailwind, React Router, Dexie 6테이블, `api/`, `server/`)로 재구성했습니다. 다른 AI가 CLAUDE.md를 읽고 들어오려면 구조가 문서와 같아야 하기 때문입니다. 받은 데모의 단일 `App.tsx`와 CSS는 버렸습니다.
- 범위는 0단계(뼈대)와 1단계(직무 탐색 10화면)까지입니다. 스튜디오 챗봇 지시문, API 키, 챗봇 id는 동료가 담당하고, 코드는 환경변수 `CHATKHU_API_KEY`, `CHATKHU_BOT_EXPLORE` 자리만 비워 둡니다. CLAUDE.md의 키 3개(A/B/C)는 키 1개로 줄였고 `CHATKHU_API_KEY_A`도 읽습니다.
- 체험 모드를 두 겹으로 두었습니다. 서버가 있는데 키가 없거나 상한을 넘으면 서버가 `{demo:true}`로 시안 대본을 돌려주고, 서버가 아예 없는 GitHub Pages에서는 브라우저가 같은 대본(`server/demo/explore.json`)을 씁니다. 발표장 시연은 둘 중 어느 쪽으로도 됩니다.
- 체험 모드에서는 시안의 사용자 대사를 추천 칩으로 보여 줍니다. 발표자가 타자 없이 탭만으로 10화면을 넘길 수 있게 하려는 것입니다. 실제 연결(live) 상태에서는 보이지 않습니다.
- 챗봇 id가 없고 키만 있으면 일반 `chat/completions`에 쿠키 지시문(`server/prompts/explore-chat.ts`)을 붙여 호출합니다. 동료가 키만 먼저 가져와도 실제 대화를 볼 수 있게 하려는 것입니다.
- 사용량 카운터는 Vercel KV REST가 설정되어 있을 때만 KV를 쓰고, 아니면 서버 인스턴스 메모리를 씁니다. `@vercel/kv` 패키지를 넣지 않고 REST 호출 15줄로 대신했습니다.
- 서버로 보내는 대화는 최근 16개 메시지(사용자·쿠키 8턴)입니다. CLAUDE.md의 "최근 8턴"을 쌍 기준으로 해석했습니다. 직무 탐색 한 세션의 사용자 메시지가 6~7개라 사실상 전체가 들어갑니다.
- 쿠키 응답 안의 "- "로 시작하는 줄을 선택 칩으로 보여 줍니다. 시안 4번 화면의 업무 스타일 선택지가 말풍선 안에 목록으로 있어서, 별도 규약 없이 탭할 수 있게 했습니다.
- `<<EVENT:{"type":"analyze"}>>`가 끝내 오지 않을 때를 대비해 사용자 메시지 9개 뒤에 "지금까지 대화로 분석하기" 칩을 보여 줍니다. 챗봇 지시문이 아직 없는 상태에서도 흐름이 막히지 않게 하려는 안전장치입니다.
- 분석(`/api/extract`)이 서버에서 두 번 실패하면 502를 돌려주고 화면은 "다시 시도" 버튼을 보여 줍니다. 서버가 없어서 404가 나는 경우만 체험 모드로 돌아갑니다.
- GitHub Pages에서는 `404.html`을 `index.html` 복사본으로 두어 `/explore/chat` 같은 경로로 바로 열어도 앱이 뜨게 했습니다. 해시 라우터는 CLAUDE.md의 React Router 경로 규약과 달라서 쓰지 않았습니다.
- 빌드 base 경로는 `VITE_BASE` 환경변수로 받습니다. Pages 워크플로는 `/khu-key-demo/`를, Vercel은 빈값(`/`)을 씁니다.
- 하단 탭 5개는 모듈 첫 화면(홈, 직무 탐색 시작, 프로필, 자소서, 면접)에만 보이고 대화·결과 화면에서는 숨깁니다. 시안 2~10번 화면에 탭이 없기 때문입니다.
- 시안 7번 화면에는 다음 화면으로 가는 버튼이 없어서 "추천 직무 보기 →" 버튼을 추가했습니다. 우상단 내려받기 아이콘은 결과 문장을 클립보드에 복사하는 동작으로 두었습니다.
- 시안 9번의 "관련 직무 더 보기"는 추천 직무 목록으로 돌아가고, 사전의 관련 직무 이름을 아래에 글자로 보여 줍니다. 관련 직무 상세 화면은 만들지 않았습니다.
- 캐릭터 이미지는 PIL로 만든 자리표시 PNG(`public/char/`)입니다. 팀의 3D 캐릭터 원본이 오거나 ChatKHU 이미지 생성으로 만들면 같은 파일명으로 바꿔 끼웁니다. 시안 10번의 하트 장면용으로 `heart.png`를 추가했습니다.
- 패키지 매니저는 pnpm이고 `pnpm-lock.yaml`을 커밋합니다. `workbox-window`를 devDependency로 명시해 pnpm에서도 PWA 빌드가 됩니다. 버전은 전부 고정했습니다.

### 미룬 것

- Vercel 배포 1회(CLAUDE.md 13절 6번)는 Vercel 로그인이 필요해 하지 못했습니다. 사용자가 Vercel에서 저장소를 연결하고 환경변수를 넣으면 `api/`가 서버로 동작합니다.
- 웹 푸시, 홈·일정, 경험 카드, 자소서, 면접은 2단계 이후입니다. 탭만 자리표시로 있습니다.
- `docs/chatkhu-api.md`의 실측 표는 키를 받은 뒤 채웁니다.
- 직무 사전은 10개입니다. 팀원이 30개로 늘립니다.
