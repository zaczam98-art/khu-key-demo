# 직무 탐색 10화면 문구 (design/01_직무탐색.png 전사)

시안의 "루미"는 전부 "쿠키"로 바꿔 적었습니다. 슬래시(/)는 시안 말풍선의 줄바꿈입니다. 상태바 "9:41"과 시각 "오전 9:41"은 실제 기기 값으로 대체합니다.

## 1. 직무 탐색 시작
- 우상단: 건너뛰기
- 제목: 안녕! 나는 쿠키야 👋
- 본문: 너와 함께 딱 맞는 직무를 / 찾아볼게. / 편하게 이야기해줘!
- 버튼: 직무 탐색 시작하기 →

## 2. 자유 대화 시작
- 헤더: ‹  [아바타] 쿠키  ● 온라인
- 쿠키: 안녕! 만나서 반가워 🥰 / 우선 가볍게 이야기해보자! / 지금 취업 준비하면서 / 가장 고민되는 게 뭐야?  (오전 9:41)
- 사용자: 아직 무슨 직무가 맞는지 / 잘 모르겠어 ㅠㅠ
- 쿠키: 그렇구나! / 직무를 정하기 어려운 건 / 정말 자연스러운 일이야. / 어떤 활동을 할 때 가장 시간 가는 줄 / 모르고 몰입했던 기억이 있어?  (오전 9:41)
- 입력창: ＋  쿠키에게 메시지 보내기...  ↑

## 3. 대화가 이어지는 과정(1)
- 쿠키: 오 흥미로운 경험이네! / 그때 어떤 부분이 특히 좋았어? / 사람들과 협업하는 과정과 / 결과를 분석하는 과정 중에서 / 더 끌렸던 부분이 있을까?  (오전 9:42)
- 사용자: 사람들이랑 의견 조율하면서 / 기획하는 게 더 재미있었어. / 그리고 실제로 실행했을 때 / 좋은 반응을 보면 뿌듯했어!
- 쿠키: 멋지다! 😊 / 그럼 너는 사람들과 소통하며 / 아이디어를 구체화하고, / 결과를 만들어내는 과정에서 / 보람을 느끼는구나.  (오전 9:42)

## 4. 대화가 이어지는 과정(2)
- 쿠키: 이런 상황은 어때? / 만약 새로운 캠페인을 기획해야 하는데, / 팀원들의 의견이 서로 달라 조율이 / 필요하다면, 너는 어떻게 하고 싶어?  (오전 9:44)
- 사용자: 각자 의견을 듣고 공통된 목표를 먼저 / 정한 다음에 장단점을 정리해서 / 결정하고 싶어!
- 쿠키: 좋아! / 너는 다양한 의견을 조율하고 / 체계적으로 정리하는 데 강점이 있어 보여. / 그럼 이런 업무 스타일은 어때? / - 새로운 아이디어 기획 / - 팀원들과 협업하며 프로젝트 진행 / - 데이터나 시장 반응을 분석해 개선

## 5. 추가 질문 및 심층 탐색
- 쿠키: 좀 더 정확히 알아보기 위해 / 몇 가지 더 질문해볼게! 😉 / / 1) 데이터를 분석해서 인사이트를 / 찾는 과정도 흥미로워? / 2) 주로 어떤 분야(서비스, 상품, 콘텐츠 등) / 에 관심이 있어? / 3) 앞으로 일하면서 가장 중요하게 / 생각하는 가치는 뭐야?  (오전 9:45)
- 사용자: 1) 기본적인 분석은 재미있어 / 2) 콘텐츠나 브랜드 쪽에 관심이 많아 / 3) 내가 하는 일이 사람들에게 좋은 / 영향을 주면 좋겠어

## 6. 대화 기반 분석 중
- 헤더: 쿠키 ● 온라인
- 캐릭터(전구 💡)
- 제목: 지금까지의 대화를 바탕으로 / 너의 특징을 정리하고 있어!
- 체크 목록: 대화 내용 분석 중... / 흥미와 가치관 파악 / 강점 키워드 도출 / 적합 직무 분석 중

## 7. 탐색 결과 요약
- 헤더: ‹  탐색 결과 요약  [내려받기 아이콘]
- 카드 제목: 쿠키가 발견한 너의 키워드
- 키워드 칩: 사람들과의 협업 / 아이디어 기획 / 콘텐츠/브랜드 관심 / 긍정적인 영향 / 분석과 개선에 흥미
- 소제목: 이런 성향을 가진 것 같아!
- 체크: 다양한 사람들과 소통하는 것을 좋아함 / 아이디어를 구체화하고 실행하는 과정에서 보람을 느낌 / 데이터를 분석해 개선하는 일에도 흥미가 있음 / 사람들에게 긍정적인 영향을 주는 일을 중요하게 생각함
